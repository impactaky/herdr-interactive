# 小さいひとこと入力枠（2026-10-28、確定）

## 文脈

範囲を選んだ直後に全面を入力画面へ切り替えると、質問の根拠となる行や周囲が見えなくなる。

## 決定

同じ overlay に tab 全体の色付き静止画面と選択背景・印を描き続け、その上側または下側に小さい入力枠を描く。幅は起動元 pane 内に収め、他の pane を隠さない。高さは最大8行かつ画面の1/3以下（2026-10-28 に6行から変更。英語の案内が折り返しても入力を3行見せるため）。上下のうち余白が広い側を使い、選択行とは重ねない。余裕があれば1行の間を残す。枠を置けなければ範囲を選び直す。Esc は送信・追記なしで閉じる。

## 代替案

全面入力は周囲の情報を失う。overlay を閉じて host popup を開く案は静止画面と印を保持できず、focus の受け渡しも増える。中央固定の枠は選択箇所を隠す場合がある。

## 結果

元画面を参照しながら入力できる。長い入力は折り返して末尾を表示する。狭い端末や画面全体の選択には枠の余地がなく、範囲を小さくする必要がある。Herdr 0.9.5 の使い捨て session で日本語の描画・入力を確認する。
