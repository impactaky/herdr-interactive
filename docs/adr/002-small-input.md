# 小さいひとこと入力枠（2026-10-28）

[English](002-small-input.en.md)

## 文脈

範囲を選んだ直後に全面を入力画面へ切り替えると、質問の根拠となる行や周囲が見えなくなる。

## 決定

同じ overlay に tab 全体の色付き静止画面と選択背景・印を描き続け、選んだ行の上側または下側に小さい入力枠を描く。幅は送り元の pane 内に収め、他の pane を隠さない。高さは最大8行かつ画面の1/3以下（2026-10-28 に6行から変更。英語の案内が折り返しても入力を3行見せるため）。上下のうち余白が広い側を使い、選択行とは重ねない。余裕があれば選択行との間を1行空ける。枠を置けなければ範囲を小さく選び直すか、端末を広げて開き直す。Esc は送信・追記なしで閉じる。

## 代替案

- 全面入力: 周囲の情報を失う。
- overlay を閉じて host popup を開く: 静止画面と印を保持できず、focus の受け渡しも増える。
- 中央固定の入力枠: 選択箇所を隠す場合がある。

## 結果

元の画面を参照しながら入力できる。長い入力は折り返して末尾を表示する。選んだ行が多すぎる場合は範囲を小さくする。端末自体が小さすぎる場合は、範囲を変えても入力枠を置けないため、端末を広げて開き直す。Herdr 0.9.5 の使い捨て session で日本語の描画・入力を確認済み。
